Automatic Table of Contents

Google Docs · built from your headings

Your document is written

1Tag every section heading
Format▶ Paragraph styles▶ Heading 1▶ Apply 'Heading 1'

Faster: the styles dropdown in the toolbar (it says “Normal text”), or Ctrl + Alt + 1  /  ⌘ + ⌥ + 1

Heading 1 = main sections  ·  Heading 2 = subsections  ·  Heading 3 = smaller divisions

2Click where the contents page goes

Usually a blank page straight after the title page, before the introduction.

3Insert the table
Insert▶ Table of contents▶ choose a style
Plain text — with page numbers Dotted — dotted leader lines Links — clickable, no page numbers

For a printed or PDF essay, pick one of the two with page numbers.

Contents page builds itself ✓

↻ Changed a heading later?

The table does not refresh on its own.

Right-click the table▶ Update table of contents

Or click the table and press the circular-arrow ↻ icon that appears beside it.

⚠ The one mistake that breaks it

Text that is merely bold and made bigger is not a heading. Google Docs only reads real heading styles, so hand-formatted titles are invisible to the table and simply will not appear.

Check your work with View ▶ Show outline — every heading Docs recognises is listed there.
