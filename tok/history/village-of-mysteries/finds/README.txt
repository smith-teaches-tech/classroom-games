IMAGE SLOTS — The Village of Mysteries
======================================

Drop images into THIS folder using exactly these filenames.
Every slot has a fallback, so the deck works with none of them.

THE FOUR FINDS  (photo replaces the line drawing when present)
--------------------------------------------------------------
  find-1        Roman dodecahedron
  find-2        Neolithic carved stone ball
  find-3        Perforated baton / baton perce
  find-4        Folkton drum

  ANY of these extensions work -- .jpg .png .jpeg .webp
  The deck tries each in turn, so name the file whatever
  your download gave you. Only one file per find.

  Shown large on screens 3-6 and as thumbnails on screen 2.
  Click-to-enlarge is automatic.

  WANT: a plain object shot against a neutral background, ideally
  raking light so the surface and wear read. AVOID anything with a
  museum label, ruler, caption or watermark in frame -- the whole
  lesson depends on the objects arriving unidentified.

  WHERE TO LOOK (clean licensing):
    - Wikimedia Commons has CC-licensed photos of all four.
      Best single search terms: "Roman dodecahedron",
      "Towie ball" (the finest carved stone ball, National
      Museums Scotland), "baton perce", "Folkton drums".
    - The British Museum's collection online releases images
      under CC BY-NC-SA 4.0 -- covers the batons and the
      Folkton drums. Non-commercial classroom use fits.
