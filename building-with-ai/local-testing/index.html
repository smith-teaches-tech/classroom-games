Testing on Your Computer

Building with AI — see your app working before you push it

Stop pushing just to see if something works. Live Server runs your app on your own computer and refreshes it every time you save. Push only when it works.
Live Server doesn't run on an iPad. Your live site is still your only preview. Get a few things working, then push and check. Skip to Part 6 if you're doing Build 2 sign-in.

PART 1Install Live Server

You only do this once.

ObjectiveLive Server is installed in VS Code.
Lots of extensions have similar names. Check the name under the title says Ritwick Dey before you install.

PART 2Open your whole folder

Not just one file. The whole repository.

ObjectiveVS Code shows your repository folder in the sidebar.

Why the whole folder?

Live Server shows whatever folder you opened. If you only open one file, it has nothing to show. If you open the whole repository, your links between pages work the same way they do on GitHub Pages.

PART 3Go Live

One click.

ObjectiveYour app is open in the browser at an address starting with http://127.0.0.1.
Ln 12, Col 4UTF-8◉ Go Live
http://127.0.0.1:5500/
http://127.0.0.1:5500/your-folder-name/

What is 127.0.0.1?

It means "this computer." Nobody else can open this address. It's your private copy of the app. 5500 is the door Live Server uses.

PART 4Your new loop

Edit, save, look. No pushing.

ObjectiveYou change something, save, and see it in the browser without pressing anything else.

Nothing changed? Look at the file's tab in VS Code. A white dot means it isn't saved. Live Server only sees saved files.

PART 6Build 2: make sign-in work here

One extra step, done once.

Objective"Sign in with GitHub" works on Live Server and on your live site.

When someone signs in with GitHub, Supabase sends them back to your app. But Supabase only sends people back to addresses you've approved. If your Live Server address isn't on the list, sign-in fails.

https://yourusername.github.io/your-repo-name/
http://127.0.0.1:5500/**
https://yourusername.github.io/your-repo-name/**

What does ** mean?

"Any page inside this address." So one line covers your homepage and every project folder.

Write it in project.md. Add both addresses under Addresses. If sign-in breaks later, this is the first place to check.

PART 7Stop, then push

When it works here, send it to GitHub.

ObjectiveYour working app is pushed and live.
