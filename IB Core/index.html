IB Core Dashboard — UI Mockups

Interactive prototypes of the proposed system for International Schools Group: one place to manage CAS, the Extended Essay, and TOK, built to improve on ManageBac's visibility and workflow.

For reviewers: these are clickable UI prototypes with sample data — buttons and dropdowns are illustrative, nothing is saved. Each screen has a role switcher at the top so you can view it as a student, teacher/supervisor, and coordinator. No login required.

How to review each mockup

  • Use the role switcher in the top-right to change perspective.
  • In tables, click a student row to expand it in place (no separate pages).
  • Try the interactive bits: rubric scoring updates a live total; word-count boxes enforce IB limits; tabs toggle between assessments.
  • These are design prototypes to agree the workflow and layout — the real app would sit on Firebase / Google Cloud (pending IT review).
